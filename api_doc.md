# 接口文档
#### 域名
dev：```你猜.zeabur.app```

#### 接口描述
`/stores` 接口根据用户提供的地点列表和偏好类型，推荐驾驶时间折中的目的地。

#### 接口名
`POST /stores`
---
#### 请求体 (JSON)

| 参数名            | 字段类型       | 是否必须 | 默认值 | 最大值 | 描述                           |
| :---------------- | :------------- | :------- | :----- | :----- | :----------------------------- |
| `user_locations`  | `list[string]` | 是       | -      | -      | 用户的起始地点列表 (至少1个)。 |
| `preference_type` | `string`       | 是       | -      | -      | 期望的目的地类型 (e.g., "麦当劳")。 |
| `num`             | `integer`      | 否       | 1      | 10     | 希望推荐的地点个数。           |

**请求体样例:**
```json
{
  "user_locations": [
    "北京市朝阳区建国路87号", 
    "北京市海淀区颐和园路5号",
    "北京市通州区环球大道"
  ],
  "preference_type": "麦当劳",
  "num": 2
}
```

---
#### 响应参数

响应为一个 `Store` 对象的数组 `List[Store]`。

**`Store` 对象:**

| 字段名  | 字段类型                | 描述                                                                 |
| :------ | :---------------------- | :------------------------------------------------------------------- |
| `store` | `string`                | 推荐的地点的名称。                                                   |
| `lat`   | `float`                 | 推荐地点的纬度。                                                     |
| `long`  | `float`                 | 推荐地点的经度。                                                     |
| `address` | `string`                | 推荐地点的详细地址。                                                 |
| `time`  | `List[TimeDetail]`      | 一个包含多个 `TimeDetail` 对象的数组，每个对象代表从一个起始点到推荐地点的耗时信息。 |

**`TimeDetail` 对象:**

| 字段名     | 字段类型 | 描述                                                           |
| :--------- | :------- | :------------------------------------------------------------- |
| `location` | `string` | 起始地点的名称。                                               |
| `duration` | `string` | 从该起始地点到推荐地点的预估驾驶时间。                       |
| `tag`      | `boolean`| `true` 表示这是所有起始地点中耗时最短的，`false` 则不是。 |

**响应样例:**

```json
[
  {
    "store": "麦当劳(北京SKP店)",
    "lat": 39.907335,
    "long": 116.47161,
    "address": "北京市朝阳区建国路87号北京SKP店",
    "time": [
      {
        "location": "北京市朝阳区建国路87号",
        "duration": "大约5分钟",
        "tag": true
      },
      {
        "location": "北京市海淀区颐和园路5号",
        "duration": "大约40分钟",
        "tag": false
      },
      {
        "location": "北京市通州区环球大道",
        "duration": "约30分钟",
        "tag": false
      }
    ]
  }
]
```

```bash
-d '{
  "user_locations": [

    "北京市海淀区颐和园路5号",
    "北京市通州区环球大道"
  ],
  "preference_type": "麦当劳",
  "num": 1
}'
```
